REUSE these C# building blocks (mirror of the frontend; avoid duplicating). Namespaces under `Softela.Infra.Ui.*` and `Softela.Common.*`.

**Response wrapper** (`Common/Abstractions/Responses/Response.cs`) — the universal service return type. `Response` and `Response<T>` (has `[JsonPropertyName("data")] T? Data`). Props: `Success` (Code==SystemCodes.Success), `IsError`, `Code`, `Message`, `ObjData`. Static factories: `Ok`, `BadRequest`, `NotFound`, `Conflict`, `Forbidden`, `Unauthorized`, `Validation`, `Unexpected`, `GeneralError`, `Failure`, `Skipped`, `Create`, `Combine(list)`. `.WithData`, `Response<T>.ToResponse()`. Controllers turn it into HTTP via extension `response.GetActionResult()`. Implicit conversions allow `return someValue;` where `Response<T>` is expected (seen across services).

**Screen object model** (`UI/Abstractions/Screens/Objects/ScreenObjectBase.cs`) — `record ScreenObjectBase` {ScreenId, ObjId, ScreenCode, Type, ControlId, ParentControl, Caption, Row, Column, ClassName, FixedSize, ChildControls: List<ScreenObjectBase>, Properties: Dictionary<string,string?>, Attributes, Events, UpdatedDate}. JSON **polymorphism via discriminator `serialization_type`** (`[JsonPolymorphic]`/`[JsonDerivedType]`): `appcomponent`→AppComponentBaseScreenControl, `tabcontrol`→TabScreenControl, `tebutton`→TeButtonScreenControl, `tableeditor`→TableEditor, and `appcomponent_{NG type}`→typed AC records. `SetProperties(IEnumerable<ScreenControlPropertyDto>)` builds the case-insensitive `Properties` dict. Typed subclasses use `record AppComponentBaseScreenControl<T> where T:ScreenPropertiesBase,new()` exposing `Props => GetProps()` which lazily does `new T().SetProps(Properties)` — i.e. **`Props` is the typed view of the raw `Properties` dict**. `GenericScreenObjectDto` is the untyped fallback.

**App Component constants** (`UI/Abstractions/AppComponents/BaseAppComponents.cs`): codes `Button="BTN", QuickChart="CRT", DockContainer="DOCK", Gauge="GGR", Label="LBL", LinkList="LNK", NumericInfoBox="NIB", TableEditor="TE"` + `_NG` variants. Helpers: `IsAppComponent(code)`, `IsDockContainer(type)`, `GetDtName(name)="AC_{name}"`, `GetDtBaseName="ACBase_{name}"`, `GetDtConfig="AC_{name}_Config"`. `AppComponentProperties` { `AppComponentCode`, `DockCode` }. AC class hierarchy: AppComponentBaseScreenControl → {Button,Label,Gauge,LinkList,NumericInfoBox,QuickChart,TableEditor}AppComponent + DockContainerAppComponentBaseScreenControl (DockList/, adds Layout + DockComponents). Property interfaces: ICommonAppComponentProperties, ICommonLegacyAppComponentProperties, IDrillDownAppComponentProperties.

**Screen constants** (`UI/Abstractions/Screens/Constants.cs`, namespace `...Web.Contracts`): `Constants.ObjectTypes` (tableeditor, appcomponent, ScreenBuilder, ACDockEditor, tabcontrol, tebutton, columnbutton, columnlink, parentcontrol, screenview, Map, chart, button, textbox, Step, StepWizard, ZplEditor, customcontrol, control), `SearchType` (e/l/r/i/ni/gt/gte/lt/lte/ne/nl/isnull/notnull/sw/ew), `StaticColumns` (ADDDATE/ADDUSER/EDITDATE/EDITUSER), `DisplayTypes` (dropdown/textbox/typeahead/date_box/button/tebutton/label/session), `LogicalOperator` (AND/OR).

**Data contracts**: `GetDataResponse` (`UI/Abstractions/.../Data`) {Columns:string[], Rows:List<object>, TotalRows, `.ToList()`→ `IEnumerable<Dictionary<string,object>>`}. `GetDataRequest` (filters/paging/sort/search). `DataTemplateDto` + `DataTemplateFieldDto` (DtName, RecordId, StructureName, Fields[] with DtFieldName, DisplayType, DefaultValue, Label, Ordinal, ReadOnly, Required, AllowNull, Properties).

**Mappers & helpers**: AutoMapper profiles in `UI/Web/Services/Mappings/` (AppComponentMappingProfile, DataTemplateMappingProfile, MenuMappingProfile, ScreenBuilderMappingProfile, TranslationMappingProfile). Static mapper `ScreenMapper.cs` (`ToDomain`, `ToGenericObject`, `To{Type}AppComponent`, `SetAppComponentBaseProperties`). Extensions `UI/Web/Extensions/` (AppComponentExtensions: `MergeProperties`(override rule), `MapToAppComponentObjectByType`, `UpdateDataTemplateFields`, `PrepareAppComponentDataTemplateFromBase`, `GetDockCodeFromDt`, `ValidateAppComponentType`; ChartExtensions). `DataTemplateUtils.ConvertUserInputToValidParams`, `JsonHelper.TryParse`. Override/merge mechanics + endpoints are detailed in the backend screens/app-components reference; conventions are covered in the backend architecture reference.
